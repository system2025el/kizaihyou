## 2026-10-20（`v0.0.0`／ステージング）

対象コミット：`1312f95`〜`07aaf3e`

### 機材表をメンバー制にし、編集を1人ずつにする（`07aaf3e`）

機材表ごとにメンバーを招待して、一緒に編集・申請できるようになりました。
同時に編集すると後から保存した人が先の変更を消してしまうので、編集は1人ずつになります。

**メンバーと権限**

機材表画面の「メンバー」から、持ち主（作成者）がメンバーを招待します。
招待できるのは、この機材表システムにアカウントがある人だけです。招待しても通知は届かないので、本人には別途伝えてください。

| 権限   | できること                                                                           |
| ------ | ------------------------------------------------------------------------------------ |
| 閲覧   | 見る・Excel/PDF出力・タイムラインへのコメント・流用して新規作成                      |
| 編集   | 閲覧に加えて、編集・保存                                                             |
| 申請   | 編集に加えて、申請・取り下げ                                                         |
| 持ち主 | 全部（メンバーの招待・権限変更・外す、削除・復元・完了・作成中に戻す、ロックの解除） |

- メンバーでない人は、機材表もその過去の内容も開けません。
- 受注部担当者は、承認画面から申請時点の内容を開くため、メンバーでなくても閲覧だけできます。
- 機材表履歴一覧には、自分が作った機材表と招待された機材表が出ます。招待されたものには「招待：編集」のように自分の権限が付きます。
- 流用して新規作成した機材表は流用した人のもので、メンバーは引き継ぎません。
- メンバーの招待・権限変更・外す操作は、タイムラインに残ります。

**編集ロック**

- 機材表は閲覧の状態で開きます。「編集」を押した人だけが編集でき、他の人には「○○さんが編集中です（最終操作 3分前）」と出ます。
- 編集が終わったら「編集を終了」を押してください。画面を離れたり、タブを閉じたりしても外れます。
- 10分間操作しないとロックが外れ、他の人が編集できるようになります。外れる1分前に警告が出るので、「編集を続ける」で延長できます。
- 編集中のままPCを離れた人がいるときは、持ち主が「ロックを解除」で外せます。
- 閲覧している画面には、他の人が保存した内容が30秒ごとに反映されます。
- ロックが外れている間に他の人が保存していた場合は、保存を止めて「最新を読み込む」を案内します（気づかずに他の人の変更を上書きしないため）。

### 表の見た目（`8d25cdf`）

- ポジション（Wing Tr内など）の列を、列名の長さに合わせた幅にしました。空欄や短い名前は狭く、長い名前は広くなります（上限240px）。
- 行番号からSPAREまでの列は、横にスクロールしても左に固定されます。
- 行番号は3桁分の幅を取り、桁が増えても横のボタンがずれないようにしました。
- 数量は右寄せにしました。対象は機材表画面のTOTAL・ACTIVE・SPARE・各ポジションと、機材表承認画面の合計・受注・予備・日別在庫です。

### 表の途中に機材や行を入れる（`3b74fb0`）

各行の左端の「＋」から、その行のすぐ下に追加できます。

- **この下に機材を追加**：機材追加ダイアログで選んだ機材（付属品を含む）を、その行の下にまとめて入れます。
- **この下に空行を挿入**：手入力用の空行を1行入れます。

### 機材追加ダイアログ（`d0a1229`）

機材表画面の「機材追加」から、機材管理（kikikan）の機材明細画面と同じ操作で機材を追加できます。

1. 部門を選ぶか、機材名で検索して、機材を複数選ぶ
2. 機材表にすでにある機材が含まれていれば、1件ずつ追加してよいか確認する
3. セットオプション（付属品）がある機材は、付属品を選ぶ。「別セット選択」で同じ機材をもう1セット追加できる
4. 機材管理と同じ並び順で、入力のある最後の行の後ろに入る（付属品は「┗」付き、種類は部門名、数量は空欄）

### ログアウト（`eba16ac`）

画面右上のユーザー名を押すと「ログアウト」を選べます。ログアウトするのはその端末だけで、同じアカウントで別の端末にログインしている人には影響しません。

### 申請時の文字数チェック（`1312f95`）

機材管理へ連携する項目が、連携先の文字数を超えていると申請できないようにしました。

| 項目           | 上限    |
| -------------- | ------- |
| 公演名・場所   | 100文字 |
| 備考・行の備考 | 200文字 |

超えたまま承認されると、機材管理への連携が失敗していたためです。
この確認より前に申請されたものを承認した場合も、連携の前に止めて、直す箇所を連携失敗の履歴に残します。

### 開発・運用で気をつけること

- **DBの変更**：`scripts/db-migration/15-add-kizaihyou-member-lock.sql`を適用済みです（メンバー・編集ロックのテーブルと、版の列）。既存の機材表28件は作成者を持ち主として登録しました。DBは本番・プレビュー・ローカルで共通です。
- **Vercelの環境変数**：承認時の機材管理への連携には`KIKIKAN_DATABASE_URL`が必要です（Previewに設定）。無いと、承認はできても連携だけが失敗します（`ECONNREFUSED 127.0.0.1:5432`）。
- **アカウント**：受注部担当者以外の利用者7名を新しく登録し、受注部担当者2名のメールアドレスを正式なものに変えました。全員のパスワードは仮のものなので、**運用開始前に変更してください**。
- **機材管理（kikikan）側の変更との関係**：2026-10-07時点のkikikan（`f56cea19`）まで確認し、連携が壊れる変更は無いことを確かめました（移動伝票の受注機材ヘッダー単位化など）。ただし、kikikanは新しい受注機材ヘッダーを作るときに本番日テンプレートを展開するようになっていて、こちらは展開していません。既存の受注に明細を足したときに本番日数が0になる差があり、対応は検討中です。
- **まだ確認していないこと**：編集ロックの延長・10分での自動解除・タブを閉じたときの解除は、ブラウザでの操作をまだ確認していません。
